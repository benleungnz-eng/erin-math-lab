# 公开开发约束

当前用户指令优先：GitHub main 保存源码并通过 GitHub Actions 测试、构建、部署 GitHub Pages；不使用其他托管平台。项目只服务独立 Erin Math Lab，不访问其他学生项目。

## 教学与隐私

- 以通用七年级知识点、可操作的微步骤引导和普通数学表达为核心，不推断个体长期能力。
- 基础五题、自愿三题再自愿两题；求助不扣奖励，讲解与独立首次完成分开记录。
- 无后端、登录、监控、统计、在线AI或CDN。所有资源本地提供，学生记录只在浏览器保存。
- 当前轮锁定广州日期；刷新保留题目、输入、提示、草稿。原子保存提交、奖励与布局，多标签不重复领奖。
- 所有题目由参数生成，以精确有理数判等、实际内容指纹去重；微步骤错误不计正式提交错误。
- 版本更新不得删除学习记录；跨域迁移由用户主动备份和导入。
- 公开仓库不得放诊断原件、真实作答、学习备份、个人联系方式、密钥或账号资料。原始私人Handoff保存在仓库外，不作为公开发布文件。

## 工程与验证

使用 package-lock.json 复现开发工具。main 的工作流必须先通过逻辑、构建、浏览器和PWA检查再发布。PR不部署，部署只需Pages与OIDC权限，不需要个人Token。

资源全部相对路径，manifest范围为当前目录，SW缓存按内容与子路径隔离。子路径离线重开、显式更新保留数据、损坏存储、备份、所有指定视口均应测试。真机、主屏幕与广州网络须单列，不能用Linux Chromium冒充。
