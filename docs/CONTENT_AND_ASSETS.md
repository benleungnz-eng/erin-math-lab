# 内容、教学与资产来源

## 内容依据与边界

原始私密交接资料仅保留在仓库外。诊断附件尚未取得，未声称核验转录或长期能力。公开源码仅包含通用教学模板、合成测试、原创场景与生成角色同人图形，不发布真实学生作答或材料。

题目为参数化新题，交接示例用于教学结构，不能据单次作答推断长期理解。可选迁移题只是当次观察，不是掌握证明。

## 模板清单

| templateId  | 知识点与题型         | 步骤/难度依据               | 主要可参与动作                             |
| ----------- | -------------------- | --------------------------- | ------------------------------------------ |
| axis        | 数轴位置，数值       | 方向与位置，热身            | 点方向与目标刻度                           |
| absolute    | 绝对值，数值         | 位置与距离区分，热身        | 判断距离规则、数单位                       |
| compare     | 两个负数比较，选择   | 数轴右侧更大，热身          | 选择方向和数                               |
| sum         | 异号相加，数值       | 从负起点向右移动，热身      | 点方向、填终点                             |
| product     | 有理数乘除，分数     | 符号与两步计算              | 判断符号、乘法和除法                       |
| fraction    | 异分母分数再除负分数 | 通分→相加→倒数→乘，核心多步 | 分块观察、填等值分子、括号分子、倒数与结果 |
| square      | −a²/(−a)² 加常数     | 底数与运算顺序              | 选底数、保留符号、最后加法                 |
| coefficient | 隐含 ±1 系数         | 找系数并带符号相加          | 填省略系数、合并                           |
| polynomial  | 变量项与常数         | 分组后分别合并              | 标签分类、填写系数与常数                   |
| bracket     | 减括号的整式加减     | 每项变号，再分组，核心多步  | 选择变号后的项、分别合并                   |
| substitute  | 化简后代入负数       | 系数→代入→乘→加，核心多步   | 局部算式逐个校验                           |
| clip        | 原片−剪去+拼接       | 减法和加法应用              | 对照片段、选择操作、两步数值               |
| resources   | 原有+每包×包数       | 乘法优先，建造应用          | 先算多包，再加原有                         |
| order       | 首先计算哪段，选择   | 步骤辨析                    | 选规则与实际子表达式                       |

范围：整数与有理数、数轴/绝对值、简单乘方、整式、代入、剪辑及建造。后续学校综合题未投放。

所有模板有同参数的 observation / guidedSteps / explanation。第一级能点选择，第2级是局部输入/选择/分类，第3级展示完整数学表达。微步骤错误不加正式错误计数；示范步骤明确标记“看过示范”。基础、加练、review、transfer 明确区分。

`src/content/schedule.js` 提供14天循环配置；不是固定14套题。实际种子关联日期/阶段/题位；内容指纹由模板与语义参数生成。实例ID换名不能规避去重。每题有限重抽，耗尽时换模板；同类小题严格保留同模板且仅一题。

## 奖励与建造

初始小屋、树、路灯各3件，小屋已放置。共12种蓝图：小屋、树、路灯、桥、花圃、天线、观景台、传送门、长椅、水池、混剪亭、星灯。全部可点放/移动/旋转/收回，支持预览和撤销。

每个学习日基础阶段唯一奖励：依次解锁下3种蓝图、各2件；全解锁后发花圃/路灯各2件。自愿3题花圃1件，自愿2题星灯1件。库存不因错误、求助、缺席或收回减少。阶段奖励账本是唯一奖励来源，不重复单题加材料。

外观有赤金、薄荷、暮紫三种可保存配色；主题不改难度。咕弹可点按弹跳，短演出可跳过，无失败；三格混剪可选伙伴、换顺序、换转场并本地预览。未实现音频（默认为静音），没有强制额外小游戏。

## 原创资产

- `public/assets/station-original.png`：本次使用 image_gen 原创生成的航站场景，包含几何棱影、软团伙伴和小型调查机器人；保留为源素材。生成要求明确排除游戏IP、官方标志/材质，不包含公式。
- `station.webp`：同图压缩分发版，约144KB，无远程生成服务依赖；原PNG不进入生产 dist。
- `ling.svg`、`gu.svg`、`lu.svg`：本次手写原创矢量角色立绘；几何鳐形机器人、挎包软团、三叉调查小机器人，保持黑红金/黄/薄荷配色。没有描摹既有游戏角色，SVG透明背景。
- `public/icons/*`：由原创棱影 SVG 在本地 Chromium 渲染成PNG，包括192/512与AppleTouch180。
- 公式、数轴、分块、标签、片段和基地格由HTML/CSS/Canvas生成，不使用生成图片承载数学。
- 无外部字体、CDN、截图、音效或第三方素材。生产全量资源低于0.3MB，初始与离线总量均低于Handoff预算。具体字节数以build日志为准。

已查看生成背景，检查无文字公式、边缘/风格和压缩体积；将进一步以实际页面截图检查角色不挤占公式与草稿。系统减少动态效果和用户开关均生效。
