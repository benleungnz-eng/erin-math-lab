# v1.1.0 角色陪练与离线家长报告

正式地址：https://benleungnz-eng.github.io/erin-math-lab/
家长入口：https://benleungnz-eng.github.io/erin-math-lab/#reports

## 行为

- 七个 AI 生成角色、每个三种表情。角色名与形象来自相应游戏/动漫，并非原先的原创几何伙伴，也不是官方授权或官方素材。图集已压缩、本地缓存；旧短片记录的 ling/gu/lu 标识保留，分别显示夏特/蛋仔/Steve。原始生成文件留在仓库外。
- 正式答对立即明确显示结果，播放约 3 秒角色庆祝，不自动跳题；刷新不重播。讲解学习结束先显示“这题学完了”，再由学生点下一题。求助、错误和独立答对保持分开。
- 每个题型的解释增加规则说明和简短原创角色台词，与已保存题目内容分开。题目生成引擎及数学内容版本不变，旧会话、历史、草稿、奖励与基地不迁移、不清除。
- 基地与三格短片首次有展开的操作说明，也可随时点“怎么玩”查看。小游戏可随时玩；基础练习完成奖励不因提示减少。
- 旧轨道演出替换为约 4 秒的角色搞笑入场，可跳过、重播。静音；减少动态效果下为静态画面。

## 报告格式与兼容

`src/reports.js` 定义 `erin-learning-report` version 1，记录字段白名单：id、revision、date、stage、template、mode、errors、hint、explanation。稳定标识由学习日、阶段和题目实例组成，无设备标识、姓名、输入答案、题目全文、草稿、基地、反思备注。仅导出已有作答或求助的记录；自愿迁移题不进入正式题数。

修订号由单题累积学习状态推导，不使用每次打开页面都会变化的数据库全局 revision。重复记录去重，新修订替换旧修订，旧修订不回退，同修订内容冲突拒绝导入。多文件先全部校验合并，再一次性写入。未来不支持版本、损坏文件或存储失败不覆盖原记录。

家长报告独立存于 `erin-parent-reports-v1`，不修改学生 IndexedDB。报告页明确样本量；首次独立答对比例分母为已走完的学习流程（含看讲解与稍后再练），不是成绩评级。支持多日趋势与按错误次数排序的题型统计。页面仅展示已导入样本，非自动同步。导出累计报告也可用于恢复到另一设备。相同关卡题目被重置重做时产生不同实例，不会误覆盖原实例。

## iPad 验收

1. 在原正式地址联网打开，若出现新版本提示，完成当前关卡后点击更新。等“离线已就绪”。不要清除 Safari 网站数据。
2. 查看首页七个角色，开始每日练习。答对后应看到“答对了”、约 3 秒角色庆祝和“下一题 →”；等待也不自动跳题。刷新恢复同一题，不再庆祝。
3. 点“我不会，直接看讲解”，读完点“这题先学到这里”：应显示“这题学完了”，不会记为独立答对，再点下一题。
4. 完成基础 5 题，确认奖励入库；进入基地看操作说明、摆放物件。重开后历史与基地仍在。
5. 结算页点“角色整活小剧场”，测试跳过、重播。在设置开启减少动态效果，再查看演出和短片，应为静态展示。
6. 点“给爸爸的学习报告”，预览后选择分享或下载 JSON 文件；分享面板可选微信、AirDrop 等设备实际支持的方式。不支持文件分享时下载后手动转发。
7. 爸爸用自己的设备打开家长入口，导入文件。重复导入题数不增加；另一天的报告应累计。点击“备份累计报告”保存副本。
8. 飞行模式关闭网络，从主屏幕重新打开，继续练习、看角色、进入基地和家长报告。联网更新后核对学习记录与基地不变。

自动化浏览器尺寸测试不能代替真机 Safari、系统分享面板、Apple Pencil 或系统长期存储清理验证。
